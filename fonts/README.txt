Nunito variable font, weights 200–1000. SIL Open Font License; see OFL.txt.
Source: Google Fonts Nunito v32, https://github.com/google/fonts/tree/main/ofl/nunito
Downloaded October 22, 2026 from fonts.gstatic.com. Local copies keep typography identical offline and across phones.

The deployed files are static instances at weights 400, 500, 600, 700, 800 and 900, generated with FontTools varLib.instancer from the original variable WOFF2s above. This avoids inconsistent variable-weight rendering in WebKit. Unmodified variable sources are retained for reproducibility.
